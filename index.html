Underground Roots Software

Free, open-source tools — built by one person, in the open, for fun and for learning.

This is a small download hub for the software I build: desktop apps and firmware, no accounts, no telemetry, no catches. Right now that's three mining tools — a desktop Stratum server, a BitAxe cluster firmware, and a multi-algo CPU/GPU miner — with more landing here over time.

01 What's here

Everything on this site is free to download and runs on your own hardware — nothing here is a hosted service or requires an account.

🔓

Source-available, mostly

Most projects link straight to a public GitHub repo. A couple — like Anvil, for now — ship as a checksummed binary with the source kept private; that's called out on each project's own page.

🏠

Built for the home lab

Sized for a single operator running a node, a few ASICs, or a small BitAxe cluster — not warehouse-scale infrastructure.

🧩

Growing over time

Started with mining tools since that's what I'm building right now. More categories of software will land here as they're finished.

02 Software

Organized by category. Each card links to a dedicated page with full details, features, and downloads.

Mining Tools

TheVault

Beta v1.0.0 Desktop App

Stratum V1 solo/proxy mining app for Bitcoin-family coins. Point your ASICs at your own node, or relay them to an upstream pool — your choice, no fees unless you want them.

Learn more & download ↗ Source code ↗

ZombieOS (formerly ClusterAxe)

v1.0.0 ESP32-S3 Firmware

Open-source firmware that clusters multiple BitAxe miners behind one pool connection — zero duplicate work, unified dashboard, safe overclock tuner even standalone devices benefit from.

Learn more & download ↗ Source code ↗

Anvil

v1.0.0 Desktop App

Native Go multi-algo CPU/GPU miner (WPXF, VerusHash, Scrypt, SHA-256d, RandomX) built as a learning tool for how mining software works — and it mines for real while it teaches.

Learn more & download ↗
