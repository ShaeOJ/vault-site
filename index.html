01 What is TheVault?

TheVault is a Stratum V1 mining server, packaged as a single native desktop app you can double-click — no Docker, no command line required.

⛏️

Solo mode

Plug it into your own full node (Bitcoin, Bitcoin Cash, DigiByte, Bitcoin SV, Bitcoin Silver, and more) and build every block yourself. Every hash goes toward finding your block, paid straight to your own wallet.

🛰️

Proxy / relay mode

No full node? Forward your whole miner fleet to an upstream pool over one clean connection — ASICpool presets built in — with optional per-miner pass-through for correct individual worker stats.

🏠

Built for the home lab

Designed for the small stuff: Bitaxes, NerdMiners, NerdQAxe boards, and the rest of the home-lab fleet — not warehouse-scale operations.

Honest by design: TheVault doesn't take a cut of anything. In solo mode the block reward is 100% yours; in proxy mode you're relaying to whatever pool you choose, on whatever terms that pool sets.

02 How to use it

Four steps from download to hashing.

Install

Grab the Windows installer below and run it, or use the portable .exe if you'd rather not install anything. No admin account or dependencies needed beyond Microsoft WebView2 (already on most Windows 10/11 machines).

Choose a mode

On first launch, pick Solo (point it at your own node's RPC) or Proxy (enter an upstream pool URL — or pick one of the built-in ASICpool presets). Solo mode needs a fully-synced node; proxy mode just needs a pool address.

Point your miners at it

TheVault opens a local stratum port on your LAN. Enter that address into each ASIC's mining-pool field (Bitaxe, NerdAxe, NerdQAxe, etc.) the same way you'd enter any other pool — username/password don't matter, any value works.

Watch the dashboard

The built-in dashboard shows live hashrate, accepted/rejected shares, best share difficulty, and a miner-fleet globe. Closing the window keeps TheVault mining in the background — use the tray icon or the Shutdown button to fully quit.

Solo mode tip: run your node with -zmqpubhashblock=tcp://127.0.0.1:28332 to enable instant block detection — TheVault pushes fresh work to every miner the moment a block lands instead of waiting on the next RPC poll.

03 Features

⚡

Instant block detection

Pure-Go ZMQ hashblock subscription with an automatic RPC poll fallback if the link drops.

🖥️

ASIC auto-recognition

Miners are identified from their user-agent and shown as 4× BM1370, Bitaxe Gamma, etc. in the fleet view.

📡

LAN auto-discovery

Finds AxeOS miners on your network automatically, with power/thermal telemetry.

🎚️

Variable difficulty

Auto-tunes per miner across the full home range — from a tiny NerdMiner up to a stack of big ASICs.

📊

Live dashboard

Real-time hashrate + shares/sec charts, best-share tracking, share counters, and network stats.

🎨

Multiple themes

Several accent-color cathode themes to pick from, all applied live across the whole app.

💾

Portable by design

Config, database, and logs all live in a data/ folder next to the exe. Copy the folder, take your setup with you.

🔄

In-app updater

Checks for new releases and can update itself in place.
